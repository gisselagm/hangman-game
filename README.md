# Hangman Game
Hangman is a fun, interactive web game built with React and Vite. The project challenges players to guess a hidden word by selecting letters, with a dynamic user interface that updates the display as letters are revealed. It features a virtual keyboard for easy input, smooth animations for letter reveals (with optional Framer Motion integration), and a clean, responsive design. This project serves as a practical example of state management, component-based architecture, and user interaction in modern web development.

# Installation
To run the project please install Framer Motion library as follows: 
npm install framer-motion
